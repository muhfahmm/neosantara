## 2. Teknologi & Open Source — The Tech Stack

Neosantara dibuat dengan bantuan teknologi dan proyek open source berikut:

- **Framework web:** Next.js dan React
- **Aplikasi desktop / mobile:** Tauri dan Electron
- **Peta:** Leaflet
- **Styling:** Tailwind CSS
- **Ikon:** Lucide React
- **Basis data:** PostgreSQL

Setiap pustaka dan teknologi tetap menjadi milik para pembuatnya masing-masing. Silakan merujuk pada lisensi dan pemberitahuan hak cipta yang disertakan bersama dependensi terkait.
